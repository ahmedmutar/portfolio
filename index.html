06 — Case Study

How I approach problems.

AI PROJECT · FREELANCE CLIENT · 2024
AI-Powered Invoice & Document Processor
Claude API ASP.NET Core SQL Server React
Problem
The client received dozens of vendor invoices every week in different formats — PDFs, scans, and photos. Manual data entry took 2–3 hours a day and errors often went unnoticed until the monthly reconciliation.
Approach
Built an automated document extraction system using Claude API. Documents are sent to the API, the model pulls out the key fields — vendor, amount, date, invoice number — as structured JSON, then writes directly to the database. No model training needed — just careful prompt engineering to handle the variation in document formats.
Result
Daily input time dropped from 2–3 hours to under 15 minutes. Extraction accuracy sits above 95% for standard documents. The finance team now spends their time verifying, not typing.
FREELANCE · FULLSTACK · DEC 2020 – FEB 2021
Bintang Vet Clinic Management System
ASP.NET Core SQL Server REST API
Problem
The clinic was managing patient records, medicine stock, and transactions through spreadsheets. Monthly reports took a long time to put together and were prone to input errors that only surfaced later.
Approach
Designed the system from scratch — database schema, backend API, and UI. Started with the patient and transaction modules since those were used every day, then added the warehouse module once the core was stable.
Result
All patient data and transactions moved into one system. Monthly reports that used to be done manually can now be generated automatically in seconds.
